# VPS Monitor v1.8.0

新增 Passkey 登录和单管理员 Telegram 私聊管理，支持从 Bot 查询库存、调整监控和通知设置。

- **Passkey**：支持多设备注册、命名、删除和登录；管理凭证需验证当前密码，保留密码登录作为恢复入口。验证域名、来源、用户身份和单次挑战；普通 HTTP 禁用，不生成自签名证书。
- **Bot 权限**：后台配置的个人 User ID 是唯一管理员，仅允许其私聊操作，无需绑定；通知开关与管理权限独立。
- **管理菜单**：包含系统状态、监控创建与管理、套餐库存、通知设置、最近事件及网页后台入口。删除和全部暂停需短时一次性确认。
- **消息排版**：分区 HTML 卡片、北京时间、编号套餐与对应购买按钮；按钮导航和分页直接更新原消息，减少刷屏。
- **自定义间隔**：监控详情 → 检查间隔 → 自定义，支持 `75`、`75秒`、`5m`、`5分钟`，范围为 30–3600 秒整数；输入五分钟内有效，`/cancel` 可取消。
- **运行行为**：管理回复不受免打扰影响，通知和连通性测试仍遵守免打扰。Bot 长轮询保存进度，已有 Webhook 时报告冲突。同一 Worker 的并发监控检查复用进行中的任务。

升级保留数据库、密码和 Telegram 配置。使用 Passkey 前设置 `AUTH_ORIGIN=https://你的域名`，通过可信 HTTPS 域名访问；本机反向代理应传递 `X-Forwarded-Proto: https`。Passkey 与域名绑定，变更域名后请使用密码登录并重新添加。

验证：91 项自动化测试、密码登录与设置浏览器回归、Passkey 注册/重命名/登录/删除与移动端检查全部通过。生产安装包已验证依赖、HTTPS 限制、单次挑战、Bot 自定义间隔和 HTML 原地更新，以及解压后 API 和 Worker 正常运行。

安装包包含网页构建和生产依赖，无需服务器端构建。请下载同版压缩包与 SHA256SUMS，校验后安装。
