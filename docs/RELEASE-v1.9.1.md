# VPS Monitor v1.9.1

接入 V.PS 与 VMISS 库存监控，并调整 Telegram 卡片和测试预览。

- **V.PS**：新增独立浏览器采集，按 Performance、Edge、Cloud、Storage KVM VPS 四个产品线分类，地区保留在套餐信息中。
- **VMISS**：新增独立浏览器采集与分类解析；默认每 5 分钟采集，并限制单分类最长等待时间。
- **Telegram 卡片**：移除检测时间；商家名与套餐名合并为指向购买页的链接；售罄时该链接加删除线。配置、库存和购买链接分段显示。
- **卡片测试**：设置页每种卡片预览右上角新增“发送测试”，向已启用的 Telegram 目标发送对应模拟信息。

升级保留数据库、登录设置及 Telegram 设置。安装包包含前端构建、Adapter 浏览器依赖清单和安装脚本。
