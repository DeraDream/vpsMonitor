# VPS Monitor v1.4.1

新增可选的全部库存变化通知：监控范围内的补货、库存数量变化、售罄分别发送 Telegram 新卡片。默认补货模式保留原卡片编辑行为，未变化状态不会重复推送。

新增北京时间（UTC+8）免打扰区间，支持跨午夜。期间继续监控，暂停发送、编辑和手动测试，结束后恢复。全部变化模式保存每次检测的库存快照，历史卡片标注北京时间。通知队列和设置存储于 SQLite，重启保留。

旧设置自动补齐默认值；安装时保留商家、监控范围和 Telegram 配置。免打扰默认关闭。VMISS 未接入本版本。

验证：70 项后端测试、43 项浏览器检查和 7 项当前 VPS 页面检查通过；本地 Linux x64 安装包的 SHA256、解压启动和 Worker 心跳验证通过。使用说明见 docs/NOTIFICATIONS.md。
