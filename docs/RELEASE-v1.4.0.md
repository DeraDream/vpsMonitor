# VPS Monitor v1.4.0

新增 GreenCloud 独立商家模块，通过公开商店目录动态发现分类、套餐与库存；分类较多时使用下拉选择，支持地区筛选、配置搜索、每页二十项及跨页勾选。监控范围支持全店、指定分类和指定套餐。

保留商家公布的 CPU、RAM、磁盘类型及容量、IP、流量、端口、系统、控制面板、备份和付款周期。明确数量为零判为缺货；没有公开数量的仅标为可订购，统计与通知文案区分。每个分类首次成功建立库存基线，后续变化再通知。Bero 模块与原有配置保持独立。

默认每三百秒一轮，最多两个请求并发，每请求限时十五秒，每轮限时六十秒。单分类异常保留原库存；目录异常标记已知分类失败；目录移除的分类保留历史但不作为当前套餐展示。Worker 长时间抓取时持续更新心跳。

验证：59 项后端测试、64 项浏览器检查通过，涵盖库存数量、空分类、旧数据保留、动态分类持久化、首轮不发通知、后续通知入队、分类监控、跨页选择、地区与搜索、窄窗口、Bero 回归、登录及长抓取期间心跳。Linux x64 安装包由本地构建，SHA256 与解压运行验证通过。

相较 v1.3.0，本次发布还包含完整登录页面与持久化会话认证、无 Git 安装包的版本检查修复、窄窗口布局调整、添加监控弹窗，以及 Bero 套餐详细配置展示。暂不包含 Passkey。

安装说明见 docs/RELEASE-INSTALL.md。安装包包含构建好的前端和生产依赖，安装时保留现有业务数据与登录配置。商家模块位于 packages/adapters/src/greencloud 与 packages/adapters/src/bero-host，分别独立维护。
