# VPS Monitor v1.7.0

- Telegram 支持频道、个人私聊或同时推送，使用同一个 Bot Token，两个目标分别开关和测试。
- 频道填写 `-100…` Chat ID 或公开频道 `@用户名`，并授予机器人发布消息权限。
- 个人先私聊 Bot 发送 `/start`，再填写自己的数字 User ID 并开启个人私聊通知。本次不包含管理命令。
- 两个目标的消息 ID、卡片编辑和重试独立，一个目标失败不会重复另一个目标已发送的通知。相同目标 ID 自动去重；修改或关闭某个目标后，其旧目标待发送任务不再投递。
- 旧 Chat ID 配置继续有效，总通知开关、监控范围和免打扰规则保持有效。

86 项后端测试、15 项通知设置浏览器检查、网页构建及发行包验证通过后发布。本次未更新当前 VPS 服务，也未向真实频道或私聊发送测试消息。
