# VPS Monitor v1.9.0

重构网页补货动态、商家卡片和个人中心，新增服务端实时日志，修复监控间隔保存及日志级别显示。

- **补货动态**：前后台共用时间线，完整商家名、北京时间日期分组与时分秒；按类型筛选，滚动每批加载 30 条，空状态为“暂无当前分类状态”。后台右上角可保存刷新间隔，默认 10 秒，前台自动同步且不能修改。
- **服务日志**：API 与 Worker 实际日志，默认每 2 秒实时滚动，支持暂停、恢复和手动刷新；成功采集为 INFO，真实失败为 ERROR，日志接口需要登录。
- **个人中心**：密码与 Passkey 设置迁至独立页面，入口位于左侧底部；主页、个人中心与退出登录集中显示，版本号移至左侧顶部。
- **页面操作**：立即刷新更新当前页面并显示加载动画；操作提示居中偏上。个人中心桌面端两列，手机端单列。
- **商家卡片**：统一商家状态、分类/套餐/库存概览、分类选择与底部操作，Bero Host 和 GreenCloud 不再因分类数不同出现大片留白。
- **轮询间隔**：取消网站 30 秒最低限制，支持正整数秒数；1、5、15 秒原值保存，卡片及再次编辑一致。此前被自动改为 30 秒的任务可重新保存希望使用的间隔。

升级保留数据库、密码、Passkey 和 Telegram 设置。安装包包含网页构建和生产依赖，无需服务器构建。下载同版压缩包和 SHA256SUMS，校验后安装。

新安装的 systemd 模板已包含日志读取权限。旧安装通过网页在线升级时，如 API 尚无日志读取权限，请在服务器执行一次 `sudo usermod -a -G systemd-journal vpsmonitor`，随后执行 `sudo systemctl restart vps-monitor-api`；或使用随包安装脚本更新 systemd 模板。

验证：94 项自动化测试通过；前后台分页、刷新间隔同步、商家分类与布局、个人中心密码及 HTTPS Passkey 全流程、日志与移动端浏览器检查通过。生产发布包另行验证解压后的 API、Worker、认证、动态设置持久化及间隔保存。
