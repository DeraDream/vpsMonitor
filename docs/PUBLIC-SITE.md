# 公开库存展示

入口为站点根路径 `/`，导航包含首页、商家、套餐、动态。商家卡片进入该商家的套餐列表。套餐页默认“全部”tab，可切换具体商家。“全部”按商家分区，各商家再按官网套餐分类分区；每个分类独立分页，每页 24 条；显示官网配置、价格、地区、真实库存状态、原始购买地址。无数量的可订购套餐不虚构台数。

`/admin` 继续使用原后台登录页，右上角登录按钮进入该入口。退出返回公开首页，后台接口认证不变。

公开页面每 30 秒读取 `GET /api/public/catalog`。页面刷新仅读取数据库，不访问商家网站。首次加载失败提供重试；暂无数据提供空状态。采集失败时保留最后成功数据，具体错误由后台监控任务展示。

动态仅包含套餐上架、补货、售罄、库存数量变化和下架；记录当时价格、配置与库存快照。历史动态以检测时间排序，固定显示北京时间。普通探测成功不进入动态，TG 发送记录与运行错误不公开。最多保留 500 条套餐动态，另保留 500 条运行日志。

参考 VPSDeer 的深色布局、渐变首页标题、库存动态卡片与页面结构；展示内容仅取自本实例已接入的商家与已采集套餐。不提供用户注册、个人订阅或未实现的公开筛选。
