# VPS Monitor v1.6.0

套餐页新增默认“全部”的商家 tab。全部列表按商家分区，每个商家区内再按官网套餐分类分区，每个分类独立分页；绿云各分类不再混在全局列表中。切换商家只展示该商家及其分类，官网配置、库存与购买链接继续保留。

修复安装包部署的在线更新：检查新版本后用站内弹窗确认，确定后下载正式发布包、校验 SHA256、备份并安装。弹窗显示真实下载进度和校验、备份、安装、重启阶段，自动重连，服务恢复后自动刷新页面。后台删除监控也使用站内弹窗，不再弹系统确认框。

更新前暂停 Worker，保留数据库、登录和 TG 设置。校验失败不修改部署，替换文件失败恢复旧文件；源码更新保留快进校验并提供进度和失败回退。同一时间只能启动一个更新任务，远端版本变化需重新确认。更新状态持久化，刷新页面可恢复查看。重启 API 和 Worker 服务，不重启整台 VPS。

本地构建的安装包包含前端及生产依赖，验证记录见 docs/test-results/v1.6.0。

验证通过：83 项后端测试、71 项浏览器检查、生产服务账号的真实安装包更新及重启验收、安装包 SHA256 与解压运行校验。当前 VPS 已更新到 v1.6.0，线上商家 tab、分类分区、后台登录和真实更新检查通过，原监控范围、登录及 TG 设置保留。隔离测试不向真实频道发送测试套餐。
