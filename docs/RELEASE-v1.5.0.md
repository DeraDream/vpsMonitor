# VPS Monitor v1.5.0

新增免登录首页、商家、套餐和动态页。参考 VPSDeer 的深色展示布局，数据来自本实例数据库；保留原始购买链接和所有已解析配置。右上角“登录”进入 `/admin` 原控制台，退出回到公开首页。公开套餐列表分页展示，不增加筛选、注册或个人订阅。

动态仅展示新上架、补货、售罄、库存数量变化和下架，保留当时价格与配置快照。成功探测不再刷事件，套餐动态与运行日志分别保留最近 500 条；采集错误仍可在后台监控任务查看。

通知设置新增“新套餐上架通知”，默认开启。商家初次采集建立基线；后续新套餐自动解析并按稳定 ID 去重，包括新分类、范围外新套餐及已售罄的新套餐。新套餐开关覆盖已启用监控商家全部新品，遵守 TG 总开关、暂停与北京时间免打扰。开启不补发已有套餐，关闭取消待发新品消息。

公开接口使用字段白名单，TG 凭据、私有通知目标、后台配置与运行错误不会公开。原后台认证和监控编辑继续受保护。

发布包由本地构建，含生产依赖与前端构建；安装保留现有业务数据及登录配置。验证结果见 docs/test-results/v1.5.0。

验证通过：77 项后端测试、13 项公开页面浏览器检查、13 项绿云后台检查、11 项登录检查及 12 项通知设置检查；安装包 SHA256、解压后匿名展示、后台认证、API 和 Worker 心跳校验通过。测试使用隔离数据和模拟 TG，不向真实频道发送测试套餐。
