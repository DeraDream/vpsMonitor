## 改动

卡片列数根据可用内容宽度调整，考虑桌面侧栏；设置页在中等宽度切为单列，操作按钮、卡片标题、套餐名称和配置值可换行。弹窗在小屏保留边距并可整体滚动，避免多层滚动区域互相挤压。320px 到 1440px 共九种宽度检查通过。

“添加监控”始终立即打开弹窗，不再因为全部商家已有任务而无反馈。先选择商家，再选择全店或指定套餐。已有任务的商家选择后进入编辑，保存更新该任务，保持每商家一个任务的约束。未选商家、加载中或请求失败时禁止保存；加载失败有页内提示；关闭后未完成请求不会重新打开弹窗。

公共套餐模型新增 cpu、ram、nvme、ipv4、ipv6、backups、runtime 字符串字段（缺失为空字符串），configuration 为 `{label,value}` 列表，保留商家原标签和值及未来新增字段。原 name、price、billingCycle、specs 等字段保持兼容，旧 Adapter 无配置字段时仍显示 specs 摘要。

Bero 从每张套餐卡片读取 CPU、RAM、NVME、IPv4、IPv6、Backups、Laufzeit/Runtime，保留页面的原值和单位。套餐名、价格同样读取页面，不写死套餐数量或配置。Backups 是备份槽位，Laufzeit/Runtime 是周期。字段在标准化、SQLite 保存和 API 返回时保留，套餐浏览及监控编辑共用配置组件显示。Ryzen/KVM 保持独立分组，跨系列勾选仍保留。
